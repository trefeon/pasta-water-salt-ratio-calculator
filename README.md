# Salmastro: Pasta Water Salinity Calculator

Responsive, zero-dependency pasta water salt calculator for kitchen counters.

## Features
- Volume stepper & pot presets (Solo 1.5L, Family 3L, Party 5L)
- Dual units: Litres (L) and Quarts (qt) with exact conversion
- Salinity tiers: Delicato (0.5%), Tradizionale (1.0%), Ristorante (1.5%)
- Visual wave cue shifting pale to deep blue per level
- Volumetric equivalents: Fine Sea Salt, Morton, Diamond Crystal
- Rotating culinary tips and salt grain density guide
